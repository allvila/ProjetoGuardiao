# 🛡️ iGuard - Projeto Guardião

O **iGuard** é um aplicativo de segurança pessoal desenvolvido em **Java** para Android, focado na proteção de idosos ou pessoas em situações de risco. O app utiliza sensores do dispositivo para detectar quedas e movimentos bruscos, automatizando o pedido de socorro.

## 🚀 Funcionalidades

*   **Detecção de Queda:** Monitoramento em tempo real via acelerômetro.
*   **Contagem Regressiva:** Alerta visual e sonoro de 15 segundos antes do envio, permitindo o cancelamento em caso de falso alarme.
*   **Envio de SMS Automático:** Mensagem de socorro enviada para um contato de confiança configurado.
*   **Geolocalização:** Integração com GPS para informar o endereço exato da ocorrência.
*   **Configurações Personalizáveis:** Ajuste de sensibilidade do sensor e tempo de resposta.

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Java
*   **IDE:** Android Studio
*   **Interface:** XML com Material Design (Cards e Custom Selectors)
*   **API de Localização:** Google Play Services / Geocoder
*   **Persistência:** SharedPreferences
